# عدّاء المعرفة

لعبة تعليمية عربية: اركض، اجمع العملات، ومرّ من البوابة التي تحمل حرف الإجابة الصحيحة.

**تصميم وفكرة: الأستاذ عبدالرحيم مبارك الرحبي**

## العب الآن
https://abdrheem111-jpg.github.io/edu-runner/

تعمل في المتصفح على الآيباد والأجهزة اللوحية (أندرويد) والحاسوب.

## طريقة اللعب
- **باللمس:** اسحب إصبعك يميناً أو يساراً لتغيير المسار، للأعلى للقفز، وللأسفل للانزلاق.
- **بلوحة المفاتيح:** الأسهم أو A / D، والمسافة للقفز، و S للانزلاق.
- **بالكاميرا:** فعّل «تحكم بالكاميرا» وتحرك بجسمك أمام الكاميرا الأمامية.

## نصائح للآيباد
- افتح الرابط في Safari، ثم «مشاركة» ← «إضافة إلى الشاشة الرئيسية» لتفتح اللعبة كتطبيق بملء الشاشة.
- أدِر الجهاز أفقياً.
- أول تحميل يحتاج اتصالاً جيداً (حوالي ٧٠ ميجا)، وبعدها يُحفظ في المتصفح.
- النتائج والأسئلة تُحفظ في كل جهاز على حدة.
